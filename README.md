## 20x 指的是用量倍数，跟模型聪不聪明没关系

这一点被误解得最多。5x、20x 描述的是相对 Plus 的总用量定位，不是"回答质量是 5 倍""生成速度快 4 倍"。两档 Pro 的核心功能一致，差别在能跑多少。这个认知在 9 月之后更重要了：价格没调、倍率被砍，说明倍率本身才是这一段定价里唯一在变的东西。

- 单模型有独立额度。某个模型的额度用完时它会暂时不可用，等到页面上的重置时间，账号里其他模型照常能用。
